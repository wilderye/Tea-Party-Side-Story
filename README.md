# 茶话会小剧场

SillyTavern 社区提示词扩展。单独剧场可填入输入框，预设剧场通过 `{{茶话会小剧场}}` 使用。

已在 1.14.0 和 1.19.0 完成基础浏览器验收，详见 [验证记录](docs/验证记录.md)。当前为接通服务前的开发版本，默认剧场库地址尚未配置。

剧场文件位于 `submissions/<Discord消息ID>.json`，不包含投稿人账号 ID。
`npm run build` 将其打包到 `dist/`，供 Cloudflare Pages 发布：构建命令 `npm run build`，输出目录 `dist`。
将发布地址写入 `config.json` 的 `libraryUrl`。安装扩展后也可在扩展设置中填写同一个地址。

首次更新一次取得全部剧场，之后只更新变化的月包；正文保存到使用者自己的酒馆数据目录，使用时不向发布服务请求正文。

开发验证：`npm test`。内部方案草案不随公开仓库提交。
