# 第一版验证记录

2026-10-02：插件基础实现已完成，本文件区分自动验证与真实服务状态。

- Node 自动测试：月包增量、损坏拒绝、抽取规则、搜索收藏、SHA256 标准对照、直接加载扩展的事件测试通过。
- 本地 SillyTavern 1.14.0 与 1.19.0：使用独立测试环境和测试提示词，在真实 Edge 浏览器检查扩展加载、两个页签、全文、默认每页 10 条、收藏、输入框追加、真实酒馆宏解析、同次多宏一致和重生成换条。无浏览器脚本异常。

- 通过 HTTP 局域网访问也能校验内容，不依赖安全上下文的 Web Crypto。
- 浏览器测试拦截的是测试域名，未向社区投稿，未调用真实 AI。
